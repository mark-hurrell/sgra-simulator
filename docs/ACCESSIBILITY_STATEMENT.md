# Accessibility statement

Date: 2026-09-30
Application version: `1.0.0`

SGR A* provides a structured Bodies list, selected-body inspector, scene
summary, keyboard camera controls, discrete mobile camera controls, a
Configure Intruder form with illustrative presets, Recent events, and
optional sonification. The Canvas is supplementary; the structured DOM
routes provide the primary information and control paths.

Sonification is supplementary and off by default. It is mono-safe, and no
sound determines capture, ejection, collision, or any future outcome. No
measured invariant-noise threshold exists, so that channel is unavailable or
silent. No claim is made that live sonification is broadly comprehensible.

Known limits: no disabled-user study has been conducted, and this project
makes no WCAG conformance or certification claim. The target standard is
WCAG 2.2 Level AA. Current verification used automated checks and headless
Chromium browser testing.

To report an accessibility barrier, please open an issue at
<https://github.com/mark-hurrell/sgra-simulator/issues>.

Evidence: [Accessibility gate record](ACCESSIBILITY_GATE_RECORD_2026-09-11.md).
